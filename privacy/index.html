プライバシーポリシー

PYTHON × AI 実践ラボ

このページは、Pythonよっちゃんねる（以下「当チャンネル」）が運営する「カレンダープレゼント」ページ （https://yaoyama30.github.io/HP/present/、以下「本サービス」）における、 利用者の情報の取り扱いを説明するものです。

1. 本サービスが行うこと

本サービスは、利用者が Google アカウントでログインして許可した場合に限り、次の 2 点を確認し、 条件を満たした方にカレンダー（PDF）のダウンロード先を表示します。

  • 利用者が当チャンネルをチャンネル登録しているかどうか
  • 利用者が対象の動画に「いいね」（高評価）を付けているかどうか

2. アクセスする情報

本サービスは、Google の「YouTube アカウントの表示」（読み取り専用、 https://www.googleapis.com/auth/youtube.readonly）の許可を求めます。 この許可で実際に読み取るのは、上記 2 点の確認に必要な次の情報だけです。

  • 当チャンネルに対する利用者自身の登録の有無
  • 対象の動画に対する利用者自身の評価（いいね／低評価／なし）

動画の投稿・削除・編集、コメント、登録や評価の変更など、利用者のアカウントに変更を加える操作は一切行いません。

3. 情報の利用目的

読み取った情報は、プレゼントの条件を満たしているかどうかをその場で判定する目的にのみ使用します。広告、分析、利用者の追跡には使用しません。

4. 情報の保存

本サービスは、利用者の氏名、メールアドレス、チャンネルの情報、確認の結果、ログインの許可（アクセストークン）を 保存しません。判定は確認のたびに行い、結果は利用者の画面に表示するだけです。 ログインの許可は Google の仕様により約 1 時間で自動的に無効になります。

5. 第三者への提供

読み取った情報を第三者に販売・提供・共有することはありません。判定のための通信は、Google が提供するサービス （YouTube Data API、Google Apps Script）との間でのみ行います。

6. Google API サービスのユーザーデータに関するポリシーの遵守

本サービスによる Google API から受け取った情報の使用および他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定的な使用の要件を含みます）に準拠します。 本サービスは YouTube API サービスを利用しており、利用者は YouTube 利用規約に同意したものとみなされます。 Google による情報の取り扱いについては Google プライバシーポリシーをご覧ください。

7. 許可の取り消し

本サービスに与えた許可は、Google アカウントの 「第三者アプリとサービス」の設定 から、いつでも取り消すことができます。

8. Cookie など

本サービス自体は、利用者を識別するための Cookie を設定しません。Google のログイン画面では、Google が同社のポリシーに従って Cookie を使用します。

9. お問い合わせ

このポリシーや本サービスについてのお問い合わせは、ホームページのお問い合わせ欄からご連絡ください。

10. 改定

内容を変更する場合は、このページでお知らせします。
